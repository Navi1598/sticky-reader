# sticky-reader
Every morning, this project picks one short article per topic, splits it into pages sized for the Seeed reTerminal Sticky (480x800 portrait), and publishes them as web pages. Each SenseCraft design shows one page, and you read by pressing the **down** button on the Sticky.
Default: 4 topics x 4 pages = **16 designs**, published as `p01.html` ... `p16.html`.

| Pages | Topic |
|---|---|
| p01–p04 | Technology |
| p05–p08 | Politics |
| p09–p12 | Nature & Environment |
| p13–p16 | Batteries (EV & Drones) |
